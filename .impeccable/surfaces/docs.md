# API reference

Mode: Read

Audience: developers evaluating or integrating the Dulio Shortener API, plus
maintainers checking its public contract.

Job: find any operation or model quickly, understand its exact constraints,
and make a correct request without inspecting backend code.

Scope: the English documentation site in `docs/`, including guides, the
OpenAPI contract, and the interactive reference. Cloudflare account changes
remain an external deployment step.

## Direction contract

THESIS: A compact protocol handbook that exposes the real contract immediately;
it refuses a marketing homepage before the reference.

OWN-WORLD: Ink-blue reading surfaces, electric blurple actions, crisp rules,
method badges, and dense but calm technical typography.

STORY: Readers learn the base URL and authentication flow, inspect constraints,
then execute a request from the reference.

FIRST VIEWPORT: Left navigation, an overview centered on the production base
URL, and a real create-link request with its response visible beside it.

FORM: Compact developer reference, user-pinned direction
`user-pinned-protocol-reference`.

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance
